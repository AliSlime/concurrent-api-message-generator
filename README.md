# Generador de Mensajes

Hacer un llamado a una API localizada en el localhost (puerto a especificar el inicio de la ejecución)
tiene que hacer llamados simultáneos a ésta (a especificar en la ejecución) que pueden ir de 1 hasta los 500.

Puede ser en cualquier lenguaje de programación que gustes, siempre y cuando en las peticiones puedas mandar un json de approx 1KB por método post (por llamada) y que puedas usar una API key (definida en el momento de ejecución)

El json debe tener un atributo que facilite su clasificación, los demás datos pueden ser los que gustes, mientras sean aprox 1KB (puede ser un poco más o un poco menos)
